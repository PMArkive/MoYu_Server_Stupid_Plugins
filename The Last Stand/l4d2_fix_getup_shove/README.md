# [L4D2] Fix Shove On Getting Up

### Introduction
- Fix edge case(s) where survivor can shove for a blink of time when cleared from domination.
  - Proved on hunter get-up, not tested on charger pound get-ups but included in the fix.

<hr>

### Requirement
- **DHooks**

<hr>

### Installation
1. Put **plugins/l4d2_fix_getup_shove.smx** to your _plugins_ folder.
2. Put **gamedata/l4d2_fix_getup_shove.txt** to your _gamedata_ folder.
